# Dzud Watch - Монгол орны зудын эрсдэл, цаг агаар, малын тоо, бэлчээрийн систем

> **Dzud Watch** нь Монгол орны 21 аймаг ба нийслэлийн интерактив газрын зураглал, шууд (Open-Meteo API) цаг агаарын мэдээ, малын тоо толгойн статистик, бэлчээрийн даацын ачаалал, зудын эрсдэлийн үнэлгээ болон малчдад зориулсан өвс тэжээлийн бодит тооцоолуур бүхий платформ юм.

--

## 🌟 Үндсэн боломжууд

1. **Интерактив Монгол орны газрын зураг (Leaflet + GeoJSON)**:
   - 21 аймаг + Нийслэлийн албан ёсны хил хязгаар бүхий полигон зураглал.
   - 4 төрлийн харагдац:
     - 🚨 **Зудын эрсдэл** (Нэн их, Их, Дунд, Бага эрсдэлтэй аймгуудыг өнгөөр ялгана)
     - 🌾 **Бэлчээрийн даац** (1-2 дахин, 2-3 дахин, 3-аас дээш дахин хэтэрсэн ачаалал)
     - ❄️ **Цасны зузаан** (Ойрын өдрүүдийн шинээр орох цас болон цасан бүрхүүлийн зузаан)
     - 🐎 **Малын тоо толгой** (Аймгуудын нийт малын төвлөрөл)
   - Аймаг дээр дарахад дэлгэрэнгүй цонх гарч ирнэ.

2. **Бодит цагийн цаг агаарын API (Open-Meteo)**:
   - Аймгийн төв бүрийн өргөрөг, уртрагаар холбогдож шууд температур, мэдрэгдэх хүйтэн, салхины хурд, чийгшил, орох цасыг харуулна.
   - Ойрын 7 хоногийн өдөр бүрийн дэлгэрэнгүй урьдчилсан мэдээ.
   - Хэт хүйтрэлт (-30°C доош) ба цасан шуурганы автомат сэрэмжлүүлэг.

3. **Малын тоо толгой ба 5 хошуу малын бүтэц**:
   - Үндэсний Статистикийн Хорооны (ҮСХ) албан ёсны тоо баримт.
   - Адуу, Үхэр, Тэмээ, Хонь, Ямааны тоо, эзлэх хувь, 1 км² дэх нягтрал.

4. **Бэлчээрийн даацын ачаалал**:
   - ЦУОШГ-ын аргачлалаар бэлчээрийн даац хэд дахин хэтэрсэн, ургацын гарц (ц/га), өвс тэжээлийн бэлтгэл хувь.

5. **Малчдад зориулсан шуурхай зөвлөмж & Тооцоолуур**:
   - **Өвс тэжээлийн интерактив тооцоолуур**: Малын тоогоо оруулахад өвөл-хаврын хоногт шаардагдах боодол өвс, хүчит тэжээлийн шуудай, хужрын хэмжээг бодож гаргана.
   - Зудын 5 төрлийн (Цагаан, Төмөр, Хар, Хүйтний, Хавсарсан) шинж, хамгаалах тактик.
   - Өвлийн бэлтгэлийн шалгах хуудас ба ОБЕГ-ын холбоо барих утас (105).

6. **GitHub руу шууд байршуулах (Deploy) ба .ZIP татах боломж**:
   - Аппликэйшн дотроосоо 1 товшилтоор төслийн бүх эх кодыг `.zip` болгон татаж аваад GitHub-д чирж оруулах боломжтой.

---

## 🛠️ Технологийн стек

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Mapping**: Leaflet, GeoJSON (Official ADM1 Mongolia boundaries)
- **Weather API**: Open-Meteo Global Weather Models (No API key needed)
- **Build tool**: Vite 8
- **Export**: JSZip
